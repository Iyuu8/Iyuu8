## 🚀 Featured projects

### 🌱 SAHLA Farm: smart agriculture platform
An end-to-end smart farming platform. I led the architecture and the full automation pipeline.

- **Automation:** an 11-module AI pipeline built in n8n
- **Apps:** React dashboard and React Native mobile app
- **Repos:** [`SAHLA_FARM`](https://github.com/Iyuu8/SAHLA_FARM) · [`SAHLA_FARM_FRONT`](https://github.com/Iyuu8/SAHLA_FARM_FRONT)

### 🗂️ TAB Explorer: Chrome extension
A file-explorer-style tab manager that lives in Chrome's side panel. Organize tabs into **Workspaces, Folders and Links**, save open tabs, and run bulk operations. Built with Plasmo and React, and **published on the Chrome Web Store**.

- **Repo:** [`TAB-Explorer`](https://github.com/Iyuu8/TAB-Explorer) · **Landing page:** [tab-explorer-landing-page.vercel.app](https://tab-explorer-landing-page.vercel.app)

### 🗺️ MapForge: AI-operable indoor navigation
An indoor mapping and navigation platform where **humans and AI agents edit the same maps through the same backend APIs**, with no shadow state. Maps are structured as organization → building → floor → node/edge graphs, with deterministic Dijkstra routing and WebMCP agent integration. Built for the OpenAI WebMCP Challenge.

- **Stack:** Symfony, Doctrine, MySQL, React
- **Repo:** [`mapforge`](https://github.com/Iyuu8/mapforge)
